# 自動開啟附近寶箱

版本：0.9.6，繁中 Dalamud API 13。

本頁是獨立的附近開箱設定。[自動巡查寶箱](AUTO_PATROL.md) 啟動後，會暫時對目前站開箱，不改變本頁開關；停止自動巡查後取消該次附帶的開箱。

0.10.15 的巡查模式只處理目前站，先停止移動並等待位置穩定 250 毫秒，再以 500 毫秒間隔嘗試；獨立附近開箱仍維持下述每秒一次、不必停步的行為。兩種模式都會排除戰利品清單中的原生／事件箱，讀條時不重複互動。

0.10.17 起，自動巡查期間允許戰鬥中照常嘗試目前站寶箱；停止巡查後，獨立附近開箱仍保留原有戰鬥暫停。兩者的讀條、過場、倒地、手動暫停、距離、可選取與原生視線檢查均維持不變。

## 使用方法

1. 在 `/crescent` 的「巡查」或「設定」勾選「自動開啟附近寶箱（2 公尺）」。兩處控制同一設定，預設關閉，重載後保留。
2. 進入新月島，自行走到可開啟寶箱 2 公尺內，地面騎乘時也會嘗試互動。範圍按包含高度的三維座標計算。
3. 靠近後首次掃描便嘗試，不必停穩；只要仍在附近且可互動便持續嘗試。關閉此開關立即停止後續互動；遊戲已開始的開箱動作不會被取消。

此功能不需要巡查路線，關閉視窗後仍工作。開箱獨立於地圖顯示篩選，包含原生 Treasure 物件與已辨識的魔法罐／兔子事件寶箱；蘿蔔、探索筆記、NPC 及其他事件物件不會互動。只處理實際載入的目標，不會對候選座標發送開箱請求。

戰鬥、讀條、互動／過場、飛行、乘坐他人坐騎、上下坐騎過程、跳躍、倒地、傳送或角色尚未就緒時暫停。「暫停巡查」也暫停自動開箱，「繼續巡查」後恢復；只終止路線不會關閉獨立的自動開箱設定。離島／登出停止，換角色／區域／分流清除嘗試狀態。

每秒至多嘗試一次，沒有次數上限；多個近距離寶箱輪流嘗試，避免一直被同一箱卡住。500 毫秒掃描間隔仍保留；開啟、走出 2 公尺或狀態不允許便停止。超過 30 秒未觀測到或離開 6 公尺的舊狀態會清除，供後續重新生成的箱子使用。已觀測開啟／淡出的原生寶箱、開啟動畫中及目前戰利品清單中的寶箱會跳過；互動請求不等於取得寶物，不會直接改寫巡查完成或上次開箱編號。

## 實作與版本核對

在 Framework 更新上使用 API 13 SDK 的 `TargetSystem.Instance()->InteractWithObject(obj, true)`。呼叫前重新尋找目標，核對物件 ID、BaseId、位置、物件種類、可選取及原生寶箱狀態。沒有跨影格快取原生物件指標。發生互動例外會停止自動開箱並記錄 Dalamud 日誌，需使用者關閉再開啟才重試。

`true` 保留原生互動函式的視線檢查選項。寶箱最終能否互動仍依遊戲判定；不修改角色位置、不自動移動或下坐騎、不繞過距離或點選確認對話。既有標點「忽略距離」設定只適用標點，與開箱無關。

參考：[FFXIVClientStructs TargetSystem 原始碼](https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/Game/Control/TargetSystem.cs)。以專案隨附的繁中 SDK 與本機客戶端為實際核對依據。

唯讀工具 `tools/ChestAudit` 從 SDK 方法屬性讀取 signature，在 **2026.09.14.0000.0000** 執行檔 `.text` 中確認唯一匹配並核對解析位置：

| 方法 | 解析 RVA |
| --- | --- |
| TargetSystem.Instance | 0x291A600 |
| TargetSystem.InteractWithObject | 0x5F2D50 |
| Loot.Instance | 0x294D538 |

執行檔 SHA256：`837B9E2893D45D22C1DDE3D1A134AF2749E0C9FFF6E2EF7246B84860F855E247`。此核對不會附加到執行中的遊戲，也不會呼叫遊戲函式。

## 驗證

984 項核心檢查通過，自動開箱檢查涵蓋距離與高度界線、無效／非寶箱目標、連續重試、每秒節流、多箱輪流、移動中進出範圍、原生拒絕與例外、開啟狀態、戰鬥／地面騎乘／飛行與乘客／讀條／暫停、角色／分流切換，以及避免偽造開箱進度。ImGui 模擬點擊驗證開關雙向切換，另產生巡查頁、設定頁、暫停及放大字體預覽。

尚待遊戲內驗收：在島上開啟選項，先在 2 公尺外確認無動作，再走近一個可開的寶箱；確認開始開箱、完成後不再重複互動。分別測試戰鬥、騎乘、讀條、傳送、關閉插件視窗及關閉開關。一般寶箱與事件寶箱需分別測試，驗證原生函式及伺服器實際接受操作。

## 距離提示

0.9.6 依使用需求取消 0.9.5 的停穩等待，保留 2 公尺判定。如果遊戲仍回報距離太遠，附近會持續重試；仍須以遊戲的距離與視線判定為準。
