# 新月島一般 FATE 自動標點（0.8.0）

入口：頂部 **FATE → 事件與自動標點**，或 `/crescent fate`。「FATE 出現時自動標點」預設關閉，需自行勾選才會自動插旗；已儲存的使用者選擇保留。清單與手動插旗仍可使用。魔法罐的出現通知與尋寶追蹤保持各自的開關。

每 0.5 秒讀取 Dalamud `IFateTable` 在目前新月島區域的有效事件，包含一般及魔法罐 FATE；CE 使用另一個事件容器，本功能不使用 CE 倒數產生旗標。只處理準備／進行中的事件，排除已結束、失敗、100% 或已逾時事件。若遊戲尚未提供事件或有效座標，便無法提前標點。

- 啟用自動標點後，上島／重載時已存在的事件亦會標點。以事件 ID 及開始時間識別場次；每場成功一次後不反覆開地圖。準備轉進行、開始時間由未知補齊、同島傳送不重播。
- 地圖只有一個旗標。多場同時首次觀測時，選開始時間最新者；時間相同選距離角色最近者，最後依 ID 排序。其他事件可在清單手動插旗。後續新出現的事件可以更新旗標。
- 讀條或互動時等待；魔法罐尋寶優先，搜尋結束後只標記仍存在的待處理 FATE。事件結束或消失就取消待標點。未知座標先等待；插旗失敗間隔至少兩秒、最多三次，之後保留手動備援。
- FATE 持有標點時暫停巡查自動略過與換旗，保留路線及紀錄。事件結束或「解除本次標點並接續巡查」後恢復；使用者原本的巡查暫停仍保持。手動重新規劃、繼續巡查或插巡查旗標也會解除本次 FATE 優先權。
- 關閉自動標點會取消待處理與持有狀態，清單仍更新；重新開啟不重播關閉期間已看到的事件。離島、換分流、換角色與登出清除場次識別。

只呼叫既有地圖旗標 API，不移動角色、不參戰。解除優先權不刪除玩家旗標；有進行中巡查且自動下一站開啟時，巡查會接回下一站旗標。

離線檢查涵蓋一般／魔法罐事件、多場選擇、重複掃描、傳送、換分流、關閉再開啟、讀條與尋寶等待、過期和錯區資料、無效座標、有限重試、手動解除與手動插旗。實際遊戲中新事件出現、地圖插旗與巡查接續仍待驗收。
