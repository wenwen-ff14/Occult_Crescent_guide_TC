# CrescentCompass 安裝包

本包僅包含插件執行檔、必要資料描述、icon 與授權文件。遊戲資料已內嵌於 DLL；瘦身不更動功能或玩家設定。

完整文件與示範截圖保留在 GitHub 及同版本的 `CrescentCompass-<版本>-source.zip`，不再隨每次安裝／更新下載。

- [使用說明](https://github.com/wenwen-ff14/Occult_Crescent_guide_TC/blob/main/USER_GUIDE.md)
- [功能文件與截圖](https://github.com/wenwen-ff14/Occult_Crescent_guide_TC/blob/main/docs/README.md)
- [更新紀錄](https://github.com/wenwen-ff14/Occult_Crescent_guide_TC/blob/main/CHANGELOG.md)
- [原始碼與建置方式](https://github.com/wenwen-ff14/Occult_Crescent_guide_TC)

不要同時啟用套件庫版與本機開發版。請保留包內 DLL、JSON 及 images 資料夾在一起，不需刪除既有玩家設定。
