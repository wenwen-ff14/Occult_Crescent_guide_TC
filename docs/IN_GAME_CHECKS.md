| 外部導航接手、vnavmesh 中止 | 停止自動巡查，不取消不同的外部路徑，不重送舊移動 |
| 離島／換分流／換角色／登出／卸載 | 停止本功能的路徑；重新登入或重載不自行啟動 |
| 一圈結束、關閉主介面 | 一圈結束停止，不自行清紀錄重跑；主介面關閉仍可巡查與使用浮窗控制 |

若回報問題，請提供插件版本、Dalamud 版本、區域 ID、X/Y 及相關 Dalamud 記錄。物件識別常數可能需要依繁中客戶端版本調整。
