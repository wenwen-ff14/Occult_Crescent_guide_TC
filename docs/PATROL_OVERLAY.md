# 巡查進度浮窗（0.10.12）

在「巡查」或「設定」頁勾選 **在畫面顯示巡查進度**；巡查下拉選單也有相同開關。預設關閉，啟用後主介面關閉時仍顯示。

## 顯示內容

- 下一站圖表編號與地點種類。
- 下一站地圖座標、角色到該點的直線距離。
- 巡查進度條、已巡查／略過／待巡與總站數。略過數獨立列出，不當成已開箱。
- 巡查中、使用者暫停、規劃路線或魔法罐／FATE 優先，以及目前狀態說明。

浮窗直接讀取現有南部 68 點巡查資料，不依賴主視窗開啟。暫停或事件優先時保留巡查目標，顯示「保留站點」。

## 控制按鈕

- **下一站**：將目前站點記為已巡查，再切到下一站；不寫入已開箱紀錄。暫停、規劃、魔法罐／FATE 優先或遊戲忙碌時停用。
- **暫停／繼續**：暫停後保留目前站點，按鈕改成「繼續」；恢復時沿用既有巡查流程。
- **終止**：終止目前巡查並隱藏浮窗，既有巡查及開箱紀錄保留。

鎖定位置後按鈕仍可點擊；巡查浮窗保留滑鼠操作，魔法罐倒數的滑鼠穿透設定獨立運作。

## 移動與顯示時機

1. 巡查開始後按「調整位置」，拖曳巡查浮窗的標題移動。
2. 放開滑鼠立即保存位置；按「完成調整」鎖定位置，按鈕仍可操作。
3. 「重設巡查浮窗位置」回到左上區，預設位於魔法罐浮窗下方。

開關、鎖定與位置會儲存，魔法罐倒數和巡查浮窗可各自設定。解析度縮小時，超出畫面的浮窗會移回可見範圍。

有剩餘站點或路線正在規劃時顯示；暫停時保留供繼續。最後一站完成、終止、沒有可用站點且未在規劃，或尚未開始巡查時自動隱藏；解鎖位置也不會顯示閒置浮窗。僅在新月島有效遊戲狀態顯示；離島、登出、傳送、過場、Gpose 或隱藏遊戲介面時隱藏。

## 驗證

已離線檢查鎖定與解鎖狀態的下一站、暫停／繼續、終止按鈕；按鈕操作不會拖動視窗。暫停、規劃、事件優先及遊戲忙碌時下一站停用；最後一站、終止、完成、無目標與閒置狀態隱藏。另已檢查拖曳保存、畫面邊界、150% 字體與雙浮窗顯示。巡查頁／設定頁開關互動已驗證，巡查設定不會改動魔法罐設定。

遊戲內的即時換站、重載後位置及轉場隱藏仍待驗收。
