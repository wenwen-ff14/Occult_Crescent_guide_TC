# CrescentCompass｜新月島尋寶羅盤

繁中服 Dalamud API 13 插件，支援寶箱巡查、魔法罐、FATE／CE、探索筆記與標點預設。輸入 `/crescent` 開啟。

## 安裝

在 Dalamud「自訂套件庫」加入：

```text
https://raw.githubusercontent.com/wenwen-ff14/Occult_Crescent_guide_TC/main/pluginmaster.json
```

重新整理插件列表，搜尋 **CrescentCompass** 安裝或更新。地形路線需搭配相容 API 13 的 vnavmesh。

[下載 0.9.4](https://github.com/wenwen-ff14/Occult_Crescent_guide_TC/raw/refs/heads/main/packages/CrescentCompass/0.9.4.0.zip) · [使用說明](USER_GUIDE.md) · [更新紀錄](CHANGELOG.md) · [建置方式](BUILDING.md)

自動開箱預設關閉，支援地面騎乘；實際開箱與標點放置仍需遊戲內驗收。
